AngularJS Demo

The <ng-barcode-febraban> directive renders an ITF barcode in real-time as you type, using two-way ng-model binding.

Type a numeric sequence above
app.js Module setup 
// 1. Install
// npm install @allansli/angular-barcode-febraban

// 2. Add script + CSS to HTML
// <script src="node_modules/@allansli/angular-barcode-febraban/dist/angular-barcode-febraban.min.js"></script>
// <link rel="stylesheet" href="node_modules/@allansli/barcode-febraban-core/assets/css/barcode.css" />

// 3. Declare dependency
angular.module("myApp", ["angular-barcode-febraban"]);
template.html Directive usage 
<!-- Static -->
<ng-barcode-febraban
  barcode-sequence="1234567890"
></ng-barcode-febraban>

<!-- Dynamic — re-renders on every input change -->
<input type="text" ng-model="vm.sequence" />
<ng-barcode-febraban
  barcode-sequence="{{vm.sequence}}"
></ng-barcode-febraban>
How it works: The directive observes the barcode-sequence attribute via attrs.$observe. On each change it calls barcodeFebrabanCore.generateBarcodeSequence() which maps every 2-digit pair to a character code in the BarcodeInterleaved2of5 font. The result is set on the scope and rendered inside a .barcodei2of5 div.
