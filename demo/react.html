React Demo

The <BarcodeFebraban> component re-renders instantly as the controlled input state changes via the useState hook.

App.jsx Component usage 
import { useState } from "react";
import BarcodeFebraban from "@allansli/react-barcode-febraban";
import "@allansli/barcode-febraban-core/assets/css/barcode.css";

export default function App() {
  const [sequence, setSequence] = useState("1234567890");

  return (
    <div>
      <input
        value={sequence}
        onChange={e => setSequence(e.target.value)}
      />
      <BarcodeFebraban sequence={sequence} />
    </div>
  );
}
Props Component API 
// All props
<BarcodeFebraban
  sequence="1234567890"   // string | number  (required)
  className="my-class"   // string           (optional extra CSS class)
  style={{ color: "#000" }} // object           (optional inline styles)
/>
How it works: On each render, the component calls generateBarcodeSequence(String(sequence)) from @allansli/barcode-febraban-core. The result is placed inside a <div className="barcodei2of5"> which the BarcodeInterleaved2of5 font renders as a visual barcode. Invalid or odd-length inputs render as an empty barcode.
