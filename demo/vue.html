Vue 3 Demo

The BarcodeFebraban component re-renders reactively as v-model updates the sequence via the Composition API.

Type a numeric sequence above Sequence must be numeric and even-length
App.vue Component usage 
<template>
  <div>
    <input v-model="sequence" />
    <BarcodeFebraban :sequence="sequence" />
  </div>
</template>

<script setup>
import { ref } from "vue";
import { BarcodeFebraban } from "@allansli/vue-barcode-febraban";
import "@allansli/barcode-febraban-core/assets/css/barcode.css";

const sequence = ref("1234567890");
</script>
main.js Global plugin registration 
import { createApp } from "vue";
import App from "./App.vue";
import { BarcodeFebrabanPlugin } from "@allansli/vue-barcode-febraban";
import "@allansli/barcode-febraban-core/assets/css/barcode.css";

createApp(App)
  .use(BarcodeFebrabanPlugin) // registers <BarcodeFebraban> globally
  .mount("#app");
How it works: The SFC uses a computed property that calls generateBarcodeSequence() from @allansli/barcode-febraban-core whenever the sequence prop changes. Vue's reactivity system ensures the barcode re-renders automatically. The plugin installer registers the component globally so you can use <BarcodeFebraban> in any template without importing it.
